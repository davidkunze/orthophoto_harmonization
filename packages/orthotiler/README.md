# OrthoTiler

Python package for automated orthophoto processing.

## Features

- Raster discovery
- GDAL VRT creation
- Raster reprojection
- Flexible raster tiling
- Cloud Optimized GeoTIFF generation
- NoData clipping
- Footprint generation
- Metadata integration
- Adaptive raster pyramids

## Installation

Install in development mode:

    pip install -e .

## Requirements

- Python 3.12
- GDAL
- Rasterio
- Fiona
- GeoPandas
- Shapely
- NumPy
- Pandas

GDAL command line utilities must be available
in the system PATH.
